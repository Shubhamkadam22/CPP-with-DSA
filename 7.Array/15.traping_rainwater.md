# 🌧️ Trapping Rain Water — $O(N)$ Two-Pointer Approach

## 1. Problem Statement
Given $N$ non-negative integers representing an elevation map where the width of each bar is $1$, compute how much water it can trap after raining.

* **Mandatory Data Structure:** `std::vector<int>` (Dynamic Array)
* **Time Complexity:** $O(N)$ — Single pass through the vector.
* **Space Complexity:** $O(1)$ — Auxiliary space using two pointers.

---

## 2. Core Intuition

For any bar at index `i`, the height of trapped water above it depends on the **tallest bar to its left** and the **tallest bar to its right**:

$$\text{Water at index } i = \min(\text{leftMax}, \text{rightMax}) - \text{height}[i]$$

> **Key Two-Pointer Insight:**  
> We don't need to know *both* maximum heights exactly—we only care about the **smaller** of the two. If `leftMax < rightMax`, the water level at the left pointer is limited solely by `leftMax`, so we can safely compute trapped water at the left pointer and move inward.

---

## 3. Step-by-Step Solving Approach

1. **Initialize Pointers and Trackers:**
   * `left = 0`, `right = height.size() - 1`
   * `leftMax = 0`, `rightMax = 0`
   * `totalWater = 0`

2. **Traverse the Vector (`left < right`):**
   * **If `height[left] <= height[right]`:**
     * If `height[left] >= leftMax` $\rightarrow$ Update `leftMax = height[left]`.
     * Else $\rightarrow$ Add trapped water: `totalWater += leftMax - height[left]`.
     * Increment `left++`.
   * **Else (`height[left] > height[right]`):**
     * If `height[right] >= rightMax` $\rightarrow$ Update `rightMax = height[right]`.
     * Else $\rightarrow$ Add trapped water: `totalWater += rightMax - height[right]`.
     * Decrement `right--`.

3. **Return Result:**
   * Return `totalWater`.
