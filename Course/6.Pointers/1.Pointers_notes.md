# Introduction to Pointers

Pointers store the memory address of another variable. They are useful when we want to work with memory directly, share data efficiently, or change values through references.

## Basic Concepts of Memory

Every variable is stored in memory at some address. A pointer keeps that address instead of the value itself.

## Address-of Operator

The `&` operator gives the address of a variable.

## What are Pointers?

A pointer is a variable that stores the address of another variable.

## Dereference Operator

The `*` operator is used to access the value stored at the address a pointer holds.

## Null Pointers

A null pointer does not point to any valid memory location. In C++, it is often written as `nullptr`.

## Passing Arguments by Value and Reference

When a value is passed to a function, the original variable is not changed. When a reference or pointer is used, the function can modify the original variable.

## Reference Variables

A reference is another name for the same variable. It is created using `&` in a declaration.

## Important Points

- `&x` gives the address of `x`.
- `int* p` declares a pointer to an integer.
- `*p` gives the value stored at the address.
- `nullptr` means the pointer is not pointing anywhere.
- References are easier to use when you want an alias for a variable.

## Example Idea

If `x = 10`, then `p = &x` stores the address of `x`. Using `*p` gives `10`, and changing `*p` changes `x` too.
