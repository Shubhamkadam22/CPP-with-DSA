# 📈 Best Time to Buy and Sell Stock — $O(N)$ Greedy / Single Pass Approach

## 1. Problem Statement
You are given an array `prices` where `prices[i]` is the price of a given stock on the $i^{\text{th}}$ day.

You want to maximize your profit by choosing a **single day to buy** one stock and choosing a **different day in the future to sell** that stock. Return the maximum profit you can achieve from this transaction. If you cannot achieve any profit, return `0`.

* **Time Complexity:** $O(N)$ — Single pass through the array.
* **Space Complexity:** $O(1)$ — Only tracking two scalar variables.

---

## 2. Core Intuition

To maximize profit from a single buy-and-sell transaction:

> **"You want to buy at the lowest possible price seen so far and sell at the highest possible price after that day."**

Instead of comparing every buy-sell pair with two nested loops ($O(N^2)$), keep track of the **minimum buying price** as you iterate through the array day-by-day.

---

## 3. Step-by-Step Solving Approach

1. **Initialize Variables:**
   * `minPrice = INT_MAX`: Tracks the minimum stock price seen so far. Initialize to `INT_MAX` so any real price will be smaller.
   * `maxProfit = 0`: Tracks the maximum profit possible. Initialize to `0` (since if no profit can be made, you don't buy).

2. **Traverse the Array (Single Loop):**
   * **Step A:** Check if the current day's price is lower than `minPrice`. If so, update `minPrice`:
     $$\text{minPrice} = \min(\text{minPrice}, \text{prices}[i])$$
   * **Step B:** Calculate the profit if you sold today ($\text{prices}[i] - \text{minPrice}$) and update `maxProfit`:
     $$\text{maxProfit} = \max(\text{maxProfit}, \text{prices}[i] - \text{minPrice})$$

3. **Return Result:**
   * Return `maxProfit`.

---

## 4. Dry Run Walkthrough

**Input Array:** `[7, 1, 5, 3, 6, 4]`

| Day `i` | Price `prices[i]` | `minPrice` (Updated) | Profit Today (`prices[i] - minPrice`) | `maxProfit` (Updated) |
| :---: | :---: | :---: | :---: | :---: |
| `0` | `7` | `7` | $7 - 7 = 0$ | `0` |
| `1` | `1` | **`1`** | $1 - 1 = 0$ | `0` |
| `2` | `5` | `1` | $5 - 1 = 4$ | **`4`** |
| `3` | `3` | `1` | $3 - 1 = 2$ | `4` |
| `4` | `6` | `1` | $6 - 1 = 5$ | **`5`** |
| `5` | `4` | `1` | $4 - 1 = 3$ | `5` |

**Final Maximum Profit:** `5` (Buy on Day 1 at price `1`, sell on Day 4 at price `6`).

---

## 5. C++ Implementation (LeetCode #121 Compatible)

```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int minPrice = INT_MAX;
        int maxProfit = 0;

        for (int i = 0; i < prices.size(); i++) {
            // Step A: Track the lowest buying price seen so far
            minPrice = min(minPrice, prices[i]);

            // Step B: Track the maximum profit if sold today
            int currentProfit = prices[i] - minPrice;
            maxProfit = max(maxProfit, currentProfit);
        }

        return maxProfit;
    }
};
