# 🚀 Kadane's Algorithm — Maximum Subarray Sum

## 1. Problem Statement
Given an integer array `nums`, find the contiguous subarray (containing at least one number) which has the largest sum, and return **its sum**.

* **Time Complexity:** $O(N)$
* **Space Complexity:** $O(1)$

---

## 2. Core Intuition

Kadane's Algorithm relies on a simple greedy principle:

> **"A negative sum subarray will only reduce the overall sum of any future subarray."**

* **Carry over:** If the running sum (`curSum`) is **positive**, it helps increase the sum of future elements.
* **Reset to 0:** If `curSum` drops **below zero**, reset it back to `0` because continuing with a negative sum will only pull down the sum of subsequent elements.

---

## 3. Step-by-Step Solving Approach

1. **Initialize Variables:**
   * `curSum = 0`: Tracks the sum of the current contiguous subarray.
   * `maxSum = INT_MIN`: Stores the maximum sum found so far (initialized to `INT_MIN` to handle all-negative arrays).

2. **Traverse the Array (Single Loop):**
   * **Step A:** Add the current element to `curSum` $\rightarrow$ `curSum += nums[i]`.
   * **Step B:** Update `maxSum` if `curSum` is greater $\rightarrow$ `maxSum = max(maxSum, curSum)`.
   * **Step C:** If `curSum` drops below `0`, reset it $\rightarrow$ `if (curSum < 0) curSum = 0`.

3. **Return Result:**
   * Return `maxSum`.

---

## 4. Dry Run Walkthrough

**Input Array:** `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`

| Index `i` | Element `nums[i]` | `curSum` (Before Reset) | `maxSum` | Action / `curSum` (After Reset) |
| :---: | :---: | :---: | :---: | :--- |
| `0` | `-2` | `-2` | `-2` | `curSum < 0` $\rightarrow$ Reset `curSum = 0` |
| `1` | `1` | `1` | `1` | Keep `curSum = 1` |
| `2` | `-3` | `-2` | `1` | `curSum < 0` $\rightarrow$ Reset `curSum = 0` |
| `3` | `4` | `4` | `4` | Keep `curSum = 4` |
| `4` | `-1` | `3` | `4` | Keep `curSum = 3` |
| `5` | `2` | `5` | **`5`** | Keep `curSum = 5` |
| `6` | `1` | `6` | **`6`** | Keep `curSum = 6` |
| `7` | `-5` | `1` | `6` | Keep `curSum = 1` |
| `8` | `4` | `5` | `6` | Keep `curSum = 5` |

**Final Maximum Subarray Sum:** `6` (from subarray `[4, -1, 2, 1]`)

---

## 5. C++ Implementation (LeetCode Compatible)

```cpp
#include <vector>
#include <algorithm>
#include <climits>
using namespace std;

class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int curSum = 0;
        int maxSum = INT_MIN;

        for (int i = 0; i < nums.size(); i++) {
            // Step A: Add current element
            curSum += nums[i];

            // Step B: Update maximum found so far
            maxSum = max(maxSum, curSum);

            // Step C: Reset curSum if it goes negative
            if (curSum < 0) {
                curSum = 0;
            }
        }

        return maxSum;
    }
};
