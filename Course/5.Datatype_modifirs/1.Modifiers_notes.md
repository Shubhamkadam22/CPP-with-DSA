# Data Types and Type Modifiers in C++

In C++, data types decide what kind of value a variable can store. Type modifiers help adjust the range, size, or sign of built-in types.

## Basic Data Types

- `int` for whole numbers.
- `float` for decimal values.
- `double` for larger decimal precision.
- `char` for single characters.
- `bool` for true or false values.

## Type Modifiers

- `signed` stores both positive and negative values.
- `unsigned` stores only zero and positive values.
- `short` uses less memory for smaller integer values.
- `long` uses more memory for larger values.
- `long long` is used for very large integer values.

## Important Ideas

- The size of a type can change depending on the compiler and system.
- `unsigned int` cannot store negative values.
- `long double` gives more precision than `double` on many systems.
- `sizeof` is used to check how much memory a type uses.

## Simple Example

If you need to store an age, `int` is enough. If you need only positive values like marks or counts, `unsigned int` can be useful. If you need very large numbers, `long long` is a better choice.

## Practice Thought

Try writing a program that prints the size of each type and stores one value in each. This helps you understand how modifiers change the behavior of data types.
