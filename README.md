# C++ with Data Structures & Algorithms

This repository documents my journey learning C++ alongside Data Structures and Algorithms (DSA), primarily following **"Data Structures, Algorithms, and Applications in C++" by Sartaj Sahni**.

I chose this book for its structured, step-by-step approach to core concepts and practical end-of-topic exercises.

### Repository Structure & Focus
* **DSA Fundamentals:** Learning and implementing core data structures step-by-step alongside book topics.
* **`Course/` Directory:** Dedicated to solving hands-on DSA practice problems and tracking topic-by-topic progression.
* **Practical Implementation:** Translating theoretical algorithms into clean C++ code.
